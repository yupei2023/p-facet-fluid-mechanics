# P-FACET for Simple Fluid Mechanics

Overview, explainer video, printable learning sheet, and the single-scenario Flowline practice game (85-point maximum).

Website: https://yupei2023.github.io/p-facet-fluid-mechanics/

GitHub Pages publishes `docs/` from `main`. The Simplified Chinese edition is in `docs/zh/`; its switch on the English pages is temporarily hidden. Remove `hidden` from the three English `.language-switch` links to show it again.

Checks:

```sh
node tests/flowline-state.test.cjs
node tests/flowline-zh-parity.cjs
```
